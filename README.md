# ABTalks

Mobile-first daily coding challenge prototype for Indian college students. The client is React + Vite, with all screen interactions handled locally in the browser. It includes no database or authentication.

## Run locally

1. Run `npm install` in the project root and `client`.
2. Run `npm run client` from the project root.

The client is served by Vite. Completion and proof submission are demo interactions and are not persisted.
